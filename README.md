# Джарвис для Android

Голосовой помощник в стиле Д.Ж.А.Р.В.И.С. для Samsung Galaxy A37 5G (Android 8 и новее).

## Что умеет

**Мгновенно, без интернета и нейросети:**
- время, дата, заряд батареи;
- фонарик, громкость, «выключи звук»;
- будильник («разбуди в 7:30»), таймер («таймер на 5 минут»);
- открыть любое установленное приложение («открой Телеграм»);
- звонок и SMS контакту, с подтверждением («позвони маме», «напиши Ивану буду через час»);
- поиск в Google и на YouTube;
- панели Wi-Fi, Bluetooth, авиарежима.

**Управление экраном** (после включения в «Специальных возможностях»):
- «назад», «домой», «недавние», «уведомления», «быстрые настройки»;
- «скриншот», «заблокируй экран»;
- «листай вниз / вверх», «нажми <текст кнопки>», «введи <текст>».

**Свободный разговор:** через нейросеть Ollama на ноутбуке в той же сети Wi-Fi
(или любой сервер, совместимый с OpenAI, если указать адрес и ключ в настройках).

## Сборка

Каждый `push` в ветку `main` запускает GitHub Actions. Готовый `Jarvis.apk`
появляется в разделе **Releases** репозитория, оттуда его можно скачать на телефон.

## Первый запуск

1. Установите `Jarvis.apk` и разрешите установку из этого источника.
2. Откройте Джарвиса и выдайте разрешения: микрофон, контакты, звонки, SMS.
3. «Настройки» → «Адрес нейросети»: адрес из файла `адрес для телефона.txt` на ноутбуке.
4. «Управление приложениями» → включите Джарвиса в «Специальных возможностях».
   Если переключатель неактивен: «Настройки» → «Приложения» → «Джарвис» → ⋮ →
   «Разрешить ограниченные настройки».
5. Быстрый вызов: «Настройки» → «Дополнительные функции» → «Боковая клавиша» →
   «Двойное нажатие» → «Открыть приложение» → «Джарвис».
