# Руна для Android

Голосовая ассистентка «Руна» для Samsung Galaxy A37 5G (Android 8 и новее).
Полностью автоматическая: выполняет команды сразу, без подтверждений.

## Что умеет

**Сама выполняет задачи из нескольких шагов:** открывает приложение, «смотрит» на экран
(читает кнопки и поля), нажимает, вводит текст, отправляет — и так до готового результата.
Например: «Руна, напиши в Телеграме Ивану, что я буду через час».

**Мгновенно, без интернета и нейросети:**
- время, дата, заряд батареи;
- фонарик, громкость, «выключи звук»;
- будильник («разбуди в 7:30»), таймер («таймер на 5 минут»);
- открыть любое установленное приложение или ссылку;
- звонок и SMS контакту — сразу, без переспрашивания;
- поиск в Яндексе и на YouTube;
- панели Wi-Fi, Bluetooth, авиарежима.

**Управление экраном** (после включения в «Специальных возможностях»):
«назад», «домой», «недавние», «уведомления», «скриншот», «заблокируй экран»,
«листай вниз / вверх», «нажми <текст>», «долгое нажатие <текст>», «введи <текст>», «отправь», «экран».

**Свободный разговор и автоматизация:** нейросеть Ollama на ноутбуке в той же сети Wi-Fi
(или любой сервер, совместимый с OpenAI, если указать адрес и ключ в настройках).

Слово-обращение: **«Руна»**. Голос: офлайн Piper «Ирина».
После перезагрузки телефона Руна запускается сама (через службу специальных возможностей).

## Сборка

Каждый `push` в ветку `main` запускает GitHub Actions. Готовый `Runa.apk`
появляется в разделе **Releases** репозитория. Он ставится поверх старой версии.

## Первый запуск

1. Установите `Runa.apk`.
2. Откройте Руну и выдайте разрешения: микрофон, контакты, звонки, SMS.
3. «Настройки» → «Адрес нейросети»: кнопка «Ноутбук».
4. «Управление приложениями» → включите Руну в «Специальных возможностях».
5. «Слушать всегда» → ВКЛ, затем сверните приложение и скажите «Руна».
